## Featured project: JobFit AI

**[Try it live](https://jobfitai-nbe4.onrender.com)** · **[View the code](https://github.com/ZafarSeepye/JobFitAI)**

Paste a job advert and a CV, and JobFit AI gives an honest fit score, the requirements you meet with proof from the CV, the gaps and how to close them, and a tailored CV summary.

- Built with ASP.NET Core and the Claude API, using structured outputs so every reply has the same shape
- Rate limits, input validation, prompt-injection defence and security headers to protect it in public
- 43 automated tests, GitHub Actions CI, and hosted in a Docker container on Render
